# 使用指南

## 你要解决什么

MRS 不是自动证明机，而是**把数学前沿攻关组织成可协作、可审计、可形式化对齐的流程**。

## 推荐路径（第一周）

### Day 1 — 熟悉库
1. 打开总览看板，看领域分布与示范战役  
2. 进入问题库，筛选「千禧年问题」  
3. 打开「黎曼假设」，阅读摘要 / 障碍 / 文献  

### Day 2 — 跑通示范战役
1. 进入「RH 零点谱解释进攻线」战役  
2. 打开已有 Explorer / Prover 会话，阅读输出  
3. 新建 Critic 会话，点「运行角色」  
4. 切换里程碑状态，调整 progress  

### Day 3 — 自建战役
1. 选一个你真正关心的问题（或点「录入问题」）  
2. 发起战役并写清策略  
3. 顺序跑：Explorer → Historian → Prover → Critic  
4. 把有价值的段落另存为工件（API 或后续 UI 增强）

### Day 4+ — 形式化与综合
1. Formalizer 产出 Lean 草图  
2. Synthesizer 出下周行动清单  
3. 在 knowledge/problems 中保持 MD 与认知同步  

## 状态语义

| 状态 | 含义 |
|------|------|
| open | 完全开放 |
| partial | 有重要部分结果，主命题仍开 |
| contested | 声称证明存在重大争议（如 abc/IUT） |
| active-frontier | 正在高速发展的研究纲领 |
| resolved | 已被广泛接受的解决 |

## 角色使用口诀

- **Explorer**：先地图，后深挖  
- **Historian**：先失败史，后新角度  
- **Prover**：无 [GAP] 不配叫证明  
- **Critic**：宁可错杀，不可放行  
- **Formalizer**：能引用 mathlib 绝不重写  
- **Synthesizer**：决策要可执行，不要鸡汤
